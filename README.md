# סדנת Claude · אמן דיגיטל

חומרי הסדנה לצוותי אפיון, ניהול פרויקטים ופיתוח.

## להורדה

| מה | קישור |
| --- | --- |
| הפלאגין של אמן דיגיטל | [aman-digital.plugin](aman-digital.plugin) (לוחצים על הקובץ ואז על Download) |
| סיכום פגישה לתרגיל 1 | [meeting-notes-sample.md](workshop-materials/meeting-notes-sample.md) |
| תיקיית דוגמה לתרגיל Cowork | [cowork-sample-folder](workshop-materials/cowork-sample-folder) |

## מה יש בפלאגין

| סקיל | מה הוא עושה |
| --- | --- |
| aman-digital-hld | מסמכי HLD בתבנית הבית |
| aman-proposal | הצעות מחיר בפורמט של אמן דיגיטל |
| project-brief | בריף של עמוד אחד מתוך פגישה, שרשור או RFP |
| meeting-summary | סיכום פגישה: נושאים, החלטות, משימות ושאלות פתוחות |
| implement-figma-screen | בניית מסך מפריים בפיגמה |
| rtl-prototype | התאמת מסך לעברית ו-RTL |
| frontend-design | כיוון עיצובי לממשקים חדשים |
| webapp-testing | בדיקת אב-טיפוס בדפדפן |

בנוסף: הסוכן design-reviewer, והמחברים Microsoft 365, Figma ו-Mobbin.

## התקנת הפלאגין

1. מורידים את `aman-digital.plugin`.
2. באפליקציית Claude מוסיפים אותו מעמוד הפלאגינים בהגדרות.
3. בודקים בצ׳אט חדש: "אילו סקילים זמינים לך?"

קוד המקור של הפלאגין נמצא בתיקייה `plugin-source`.

כל החומרים בתיקייה `workshop-materials` בדויים.
