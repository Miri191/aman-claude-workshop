# aman-digital

ערכת העבודה של סטודיו UX/UI באמן דיגיטל ל-Claude.

## סקילים
| סקיל | מה הוא עושה |
| --- | --- |
| aman-digital-hld | מסמכי HLD בתבנית הבית: Word ממותג מימין לשמאל, מבנה פרקים אחיד וספריית נוסחים |
| aman-proposal | הצעות מחיר בפורמט של אמן דיגיטל: טבלת שעות, תמחור ותנאים מסחריים |
| project-brief | בריף של עמוד אחד מתוך פגישה, שרשור או RFP, עם שאלות פתוחות |
| meeting-summary | סיכום פגישה בעברית: נושאים, החלטות, משימות ושאלות פתוחות |
| implement-figma-screen | בניית מסך מפריים בפיגמה, עם הטוקנים והקומפוננטות |
| rtl-prototype | התאמת מסך לעברית ו-RTL |
| frontend-design | כיוון עיצובי מכוון לממשקים חדשים: טיפוגרפיה, צבע ופריסה שלא נראים כמו תבנית |
| webapp-testing | בדיקת אב-טיפוס בדפדפן עם Playwright: צילומי מסך, לחיצות ובדיקת שגיאות |

## סוכנים
- **design-reviewer:** בודק מסך, אב-טיפוס או אפיון מול הבריף, העיצוב ומערכת העיצוב, בלי לשנות קבצים.

## מחברים
- **Microsoft 365:** Teams, Outlook, SharePoint ו-OneDrive. דורש אישור של מנהל ה-IT בארגון.
- **Figma:** קריאת מסכים, משתנים וקומפוננטות.
- **Mobbin:** חיפוש מסכים וזרימות מאפליקציות אמיתיות.

כל מחבר מבקש התחברות בפעם הראשונה, ורואה רק מה שמותר למשתמש לראות.


הסקילים frontend-design ו-webapp-testing לקוחים מהמאגר הציבורי של Anthropic (github.com/anthropics/skills), עם קובץ הרישיון שלהם.
