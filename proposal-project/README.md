# פרויקט הצעות מחיר · ערכה מוכנה

כל מה שצריך כדי להקים ב-Claude פרויקט שכותב הצעות מחיר בפורמט של אמן דיגיטל. ההקמה לוקחת כ-3 דקות.

## הקמה

1. באפליקציית Claude פותחים פרויקט חדש בשם **הצעות מחיר · אמן דיגיטל**.
2. מעתיקים את כל התוכן של `instructions.md` להוראות הפרויקט.
3. מעלים לקבצי הפרויקט את שני הקבצים שבתיקייה `knowledge`:
   - `proposal-template.docx`: תבנית ההצעה
   - `commercial-terms.md`: תעריף ותנאים
4. אם יש, מעלים גם שתיים-שלוש הצעות טובות מהעבר, בלי פרטים מזהים של לקוחות.

## שימוש

בשיחה חדשה בתוך הפרויקט מדביקים בריף או סיכום פגישה, וכותבים:

> תכין הצעת מחיר לפי התבנית. סמן כל הנחה, ותוציא קובץ Word.

לתרגול אפשר להשתמש בסיכום הפגישה שבתיקייה `workshop-materials`.

## הערה

עם הפלאגין `aman-digital` מותקן, הסקיל `aman-proposal` עושה את אותה עבודה גם מחוץ לפרויקט. הפרויקט שימושי כשרוצים שכל ההצעות של לקוח או של צוות יישבו במקום אחד.
